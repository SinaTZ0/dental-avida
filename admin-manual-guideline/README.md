# Avida Dental User & Admin Manual

Self-contained Persian user & admin manual for **Avida Dental Clinic**, styled after Cisco Press technical reference books and modeled on the `hut-start` manual pipeline.

**`manual/` is the deliverable**: open `manual/index.html` directly from disk in any browser (offline, zero external requests). Printing any chapter via **Print → Save as PDF** produces an A4 Cisco-style document with Persian page numbers and chapter running headers.

## Folder Structure

```text
admin-manual-guideline/
  README.md                   this guide
  writing-guide.md            Persian editorial rules & Cisco Press book conventions
  labels.json                 fixed UI & book strings (chapter, figure, table, key topic, ...)
  intro.md                    front page introduction
  tools/
    shoot.mjs                 captures annotated screenshots from the running app (Playwright)
    build.mjs                 compiles intro.md + chapters/*/content.md + shots.json into manual/
  chapters/<nn-name>/
    content.md                chapter text in the manual's structured Markdown format
    shots.mjs                 Playwright screenshot & callout marker definitions
    shots.json                measured pixel boxes generated by tools/shoot.mjs
  manual/
    index.html                book table of contents
    01-sign-in.html ...       one standalone HTML file per chapter
    assets/                   manual.css, manual.js, bundled Vazirmatn fonts
    images/<nn-name>/         captured PNG screenshots
```

## Rebuilding the Manual

1. Start the app locally (e.g. `pnpm dev` on `http://localhost:3000`).
2. Capture or refresh screenshots for a chapter (or all chapters):
   ```sh
   node --env-file=.env admin-manual-guideline/tools/shoot.mjs 01-sign-in --base http://localhost:3000
   ```
3. Build the HTML manual into `admin-manual-guideline/manual/`:
   ```sh
   node admin-manual-guideline/tools/build.mjs
   ```
4. Open `admin-manual-guideline/manual/index.html` in a browser.
